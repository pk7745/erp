# ERP System

An Enterprise Resource Planning (ERP) system developed to simplify and automate organizational management processes. The project demonstrates backend development, data management, and structured software design using Python.

---

## Overview

The ERP System is designed to centralize and manage essential operations such as user management, records, and administrative tasks through a structured software solution.

The project focuses on improving efficiency by organizing information in a single platform while demonstrating software engineering principles.

---

## Features

- User Management
- Student & Record Management
- Organized Data Storage
- Modular Project Structure
- Easy Navigation
- Scalable Architecture
